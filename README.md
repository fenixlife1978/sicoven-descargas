# SICOVEN Descargas

Landing page estática para presentar y distribuir SICOVEN, software contable de escritorio.

## Arquitectura del producto

SICOVEN es una aplicación de escritorio para Windows. Utiliza SQLite local como base de datos y fuente de verdad de la información contable. Esta web es únicamente informativa y distribuye el instalador oficial; no procesa operaciones contables, no aloja bases de datos de clientes y no sincroniza información contable con la nube.

## Descarga oficial

SICOVEN v1.0.9 · Windows x64:
https://github.com/fenixlife1978/Sicoven/releases/download/v1.0.9/SICOVEN-Setup-1.0.9-x64.exe

## Despliegue en Vercel

Importar este repositorio en Vercel. No requiere base de datos, variables de entorno, backend ni comandos de build. Framework: Other. Output directory: punto (raíz del proyecto).
